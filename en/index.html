Open-source project

Video 3D Studio

Describe a shot, get a 3D video. A free Claude Code skill, put to the test with four films made from scratch, up to a 2-minute-34 race with engines synthesised in code.

Remotion · three.js · MP4 1080p

What it does

It writes each scene as code, composes an original soundtrack and renders the MP4 on the user's own computer, with no subscriptions or render credits.

How it works

Each frame is drawn 64 times and averaged, which produces soft shadows, lens blur and reflections. Before the final render, a tool scans every frame for flashes and jumps.
